# What is DocuSapiens?

**DocuSapiens** transforms your GitHub repositories into AI-powered documentation sites. Connect a repo, get a live site with built-in AI chat — no configuration required.

> Connect your GitHub repo → hosted documentation site → AI chat trained on your docs

---

## The Problem

Setting up documentation infrastructure is work that doesn't add value:

- Installing and configuring a docs framework (Docusaurus, MkDocs...)
- Setting up CI/CD and deployment pipelines
- Building and maintaining an AI chat system
- Keeping all of it in sync with your repo

DocuSapiens eliminates all of this.

---

## How It Works

1. **Sign in** with GitHub at [app.docusapiens.ai](https://app.docusapiens.ai)
2. **Select a repository** that has a `docs/` folder with Markdown files
3. **Choose a site name** — your site will be `<site-name>.docusapiens.site`
4. **Done** — DocuSapiens builds your site and trains the AI chat in ~60 seconds

Every time you push to GitHub, your site and AI rebuild automatically.

---

## What You Get

### Live documentation site
A professional, fast documentation site at `<site-name>.docusapiens.site`. Clean theme, dark mode, mobile responsive, SEO-friendly.

### AI chat — trained on your docs
Users ask questions and get answers grounded in your actual documentation. The AI never invents information — it only references what's in your docs. [How it works →](./ai-chat.md)

### Automatic GitHub sync
Every push triggers a rebuild. Your docs and AI are always in sync with your repository. No manual steps.

### No lock-in
Your content is plain Markdown in your own GitHub repository. You own it.

## Use Cases

- **Open source projects** — Free hosted docs that auto-update with every release. Users get answers without opening issues.  
- **SaaS products** — Always-current docs with built-in AI support chat. Fewer support tickets.  
- **Internal teams** — Company knowledge bases and runbooks. New hires get instant answers.
